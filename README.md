# DhuyeDaw – On-Demand E-Laundry Service

## Project Overview
**DhuyeDaw** is the city's first doorstep laundry service, offering a seamless online booking experience integrated with payments and order tracking. The platform provides a convenient way for users to schedule pickups, track orders, and make secure payments.

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Payment Integration:** bKash API

## Features
- **Online Booking** – Users can schedule laundry pickups through the platform.
- **Secure Payments** – Integrated with bKash for easy and secure transactions.
- **Order Tracking** – Real-time tracking of laundry service status.
- **Responsive Design** – Accessible on desktop and mobile devices.
